Ember live demo
Local semantic retrieval: questions and code are embedded in your browser with the quantized all-MiniLM-L6-v2 WASM model (~23 MB, downloaded once from Hugging Face's CDN and cached). Loading a repo makes anonymous fetches to GitHub's public API - public repos only, bounded at 120 files / 1.2 MB per load, GitHub's anonymous rate limit applies. No server, no account, no API keys. github.com/dp177/ember
